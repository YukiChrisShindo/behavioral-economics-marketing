# 検証方法の設計

仮説は検証されて初めて価値になる。介入案には必ず「どう確かめるか」をつける。
ただし、検証の形式は一つではない。トラフィックが少なければA/Bテストは成立しないし、価格変更のように後戻りしにくい介入もある。状況に合った検証方法を選ぶ。

---

## 検証方法の選び方

| 状況 | 向いている検証 |
|---|---|
| トラフィックが多い（月間数千以上のCV母数） | A/Bテスト |
| トラフィックが少ない | 前後比較 + 定性調査、またはフェイクドア |
| 価格・プラン構成の変更 | 段階的ロールアウト、新規ユーザーのみ対象、フェイクドア |
| 文言・UIの変更 | A/Bテスト、5秒テスト |
| 「そもそもニーズがあるか」 | フェイクドア、インタビュー |
| 継続率・解約率 | コホート比較（時間がかかる。先行指標を決める） |

---

## A/Bテストの設計型

介入案に添えるテスト設計は、この5項目を埋める。

```
- 対象：誰に（全ユーザー / 新規のみ / 特定セグメント）
- 変更：A（現状）と B（介入）の違いを一点に絞って記述
- 主指標：何が動けば成功か（1つに絞る）
- 副指標：悪化していないか見張る指標（解約率、返金率、サポート問い合わせ数など）
- 期間とサンプル：下記の目安を使う
```

### サンプルサイズの目安

厳密な計算は統計ツールに任せるが、提案段階では次の目安で「現実的か」を判断する。

| 現状のCV率 | 検出したい改善幅（相対） | 必要サンプル（各群） |
|---|---|---|
| 2% | 20%（2% → 2.4%） | 約 21,000 |
| 5% | 20%（5% → 6%） | 約 8,100 |
| 10% | 20%（10% → 12%） | 約 3,800 |
| 20% | 10%（20% → 22%） | 約 6,500 |

（有意水準5%、検出力80%の概算）

**実務上のルール**：
- 最低でも1〜2週間は回す。曜日効果を均す
- 途中で結果を覗いて止めない（覗くなら事前にその分を織り込む）
- 「有意差なし」は「効果なし」ではない。サンプル不足の可能性を常に書く

### 一度に一つだけ変える

複数箇所を同時に変えると、効いたのがどれか分からない。提案では「この介入は文言だけ」「この介入はプラン構成だけ」と分離する。どうしても複数変える場合は、それが「一つのコンセプト」として説明できるか確認する。

## 定性検証

数字で測れない、または測るまで時間がかかる場合の方法。

### 5秒テスト
ファーストビューを5秒見せて、「何のサービスか」「誰向けか」「次に何をすればいいか」を答えてもらう。認知段階の仮説に有効。5人で傾向が出る。

### 思考発話法（Think-aloud）
実際のフローを辿りながら、考えていることを声に出してもらう。「ここで迷う」「これ何？」が摩擦の位置を教えてくれる。3〜5人。

### 解約者インタビュー
解約直後に「なぜやめたか」ではなく「やめる前に何を期待していたか」「どの瞬間に離れる決心がついたか」を聞く。ピーク・エンドの悪い側が見つかる。

### フェイクドア
存在しない機能・プランへの導線を置き、クリック率で需要を測る。クリック後は正直に「準備中です」と伝えて連絡先を取る。価格テストにも使える（「年額プランに興味がある」ボタン）。
**倫理**：クリック後に正直に説明すること。騙したままにしない。

## 検証できないときの書き方

実装コストが高い、または実験できない状況でも、提案書には「効いたと分かる指標」と「効かなかったときの撤退条件」を書く。

```
- 成功の判断：導入後4週間で○○率が△△%以上
- 撤退条件：□□率が××%悪化したら戻す
- 先行指標：最終指標が出るまでの間に見る中間指標（例：解約率が出る前に、週次アクティブ率を見る）
```

## 検証結果の解釈でよくある落とし穴

- **ノベルティ効果**：新しいものは最初だけ効く。最初の1週間の数字を信じない
- **セグメントの違い**：全体では効かないが特定セグメントで効く（またはその逆）。事後にセグメントを切りすぎると偶然を拾う
- **短期と長期のズレ**：CV率は上がったが解約率も上がった、は典型的な「スラッジ化」の兆候。副指標を必ず見る
- **相関と因果**：前後比較は季節・キャンペーン・外部要因の影響を受ける。可能ならA/Bを優先する
- **前倒し効果（置き換え）**：リマインドや期限で「今週の申込」が増えても、来週の分が前倒しされただけのことが多い。狭い期間・一箇所だけで測ると効果を過大評価する。主指標とは別に、期間を2〜3倍に広げた指標、全チャネル合計の指標も見る
- **論文の効果量をそのまま使わない**：大規模な追試では、現場の効果は論文の数分の一になる。「論文で20%改善」なら「現場で数%」と見積もり、サンプルサイズもそれに合わせて多めに取る
- **やる気の層で効き方が違う**：ナッジは「やる気が中くらい」の層に効き、全くやる気のない層と、既にやる気のある層には効かない。全体で効果が出なくても、中間層だけで見ると効いていることがある（ただし事後のセグメント切りすぎには注意）
